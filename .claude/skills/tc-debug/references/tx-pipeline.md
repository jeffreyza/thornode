# Transaction pipeline: code path by stage

Read this when a `parse_tx_status.py` phase points at a stage and you need the code that runs there: which function gates it, what condition stops it, and what to grep for. Paths are relative to the repo root; read them at the `ISSUE_VERSION` tag, not develop.

Observations no longer travel as one `MsgObservedTxIn` per node. Bifrost nodes gossip signed attestations peer to peer, and once a node holds a supermajority it hands the bundle to its local thornode, whose block proposer injects it as `MsgObservedTxQuorum`. `MsgObservedTxIn`/`MsgObservedTxOut` handlers still exist but bifrost does not build them.

## Inbound: L1 tx to swap queue

| Stage               | Where                                                                                                            | Gate / what can stop it                                                                                                                                                                                                      |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scan                | chain client `FetchTxs` (`bifrost/pkg/chainclients/<chain>/`), `bifrost/blockscanner/blockscanner.go`            | Scanner lag or halt; tx not to a known vault is never emitted                                                                                                                                                                |
| Deck                | `bifrost/observer/observe.go` `processTxIns` -> `processObservedTx`                                              | Node not `Active`: observation rejected (`errObservedTxInactive`), except XMR spent-ref certificates                                                                                                                         |
| Send                | `observe.go` `sendDeck` -> `getThorchainTxIns` -> `sendObservedTxs`                                              | `final := ConfirmationCountReady(deck) && !deck.MemPool`; a pre-final observation is sent first, the final one after confirmations                                                                                           |
| Attest              | `bifrost/observer/attestation_handlers.go` `AttestObservedTx`; `attestation_gossip.go`, `attestation_batcher.go` | Inbound vs outbound decided by `thorchainBridge.GetInboundOutbound`; the attestation key includes direction and `AllowFutureObservation`                                                                                     |
| Bifrost quorum      | `attestation_handlers_impl.go` `handleObservedTxAttestationInternal` -> `sendObservedTxAttestationsToThornode`   | `types.HasSuperMajority(attestationCount, activeValidatorCount)`: counted against active validators, never the keysign committee. Log: `sent quorum tx to thornode`                                                          |
| Inject              | `x/thorchain/ebifrost/ebifrost.go` `SendQuorumTx` -> `ProposalInjectTxs`; `ebifrost/ante.go`                     | Quorum msgs are only valid when proposer-injected; ante rejects them from the mempool                                                                                                                                        |
| Verify              | `x/thorchain/handler_observed_tx_quorum.go` `handle`                                                             | `deduplicateAttestations`, `verifyQuorumAttestation` against active validators; zero valid attestations logs `quorum tx has no active attestations` and drops                                                                |
| Voter               | `x/thorchain/handler_observed_tx_helpers.go` `ensureVaultAndGetTxInVoter`, `processTxInAttestation`              | Unknown vault drops the observation (`thornode.observation.dropped` metric); consensus is `ObservedTxVoter.HasConsensus` / `HasFinalised` in `x/thorchain/types/type_observed_tx.go`                                         |
| Quorum side effects | `handler_observed_tx_helpers.go` `handleObservedTxInQuorum`                                                      | Not at quorum: attestations landing in the block that reached quorum are only recorded via `ObMgr().AppendObserver`. Reverted voter (errata) or `CompromisedVault` mimir: no-op                                              |
| Memo and refund     | same function; `ParseMemoWithTHORNames`, `resolveReferenceMemo`, `processOneTxIn` (`x/thorchain/handler.go`)     | Waits for `hasFinalised` (except migrate); inactive vault -> `refundTx` `CodeInvalidVault`; bad memo -> `CodeInvalidMemo`; `IsTradingHalt` or Ragnarok -> refund `trading halted`. `refundTx` is in `x/thorchain/helpers.go` |
| Swap queue          | `x/thorchain/handler_observed_txin.go` `addSwap`                                                                 | `msg.IsV2()` -> `AdvSwapQueueMgr().AddSwapQueueItem` (`manager_adv_swap_queue_current.go`); else `addSwapDirect` (legacy queue, being removed; mainnet runs the advanced queue)                                              |

## Outbound: scheduled item to observed L1 tx

| Stage            | Where                                                                                                                                        | Gate / what can stop it                                                                                                                                                                                                                                                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Schedule         | `x/thorchain/manager_txout_current.go` `TryAddTxOutItem` -> `prepareTxOutItem` / `DiscoverOutbounds` -> `CalcTxOutHeight` -> `addToBlockOut` | Vault selection can fail (`emitInsufficientAvailableBalanceSecurityEvent`); `CalcTxOutHeight` applies the outbound delay (`TxOutDelayRate`, `TxOutDelayMax`, `MaxTxOutOffset`) to `OUT`/`REFUND` only                                                                                                                                     |
| Fetch            | `bifrost/signer/thorchain_block_scanner.go` `processTxOutBlock` -> `bifrost/thorclient/keysign.go` `GetKeysign(height, pk)`                  | Queried per `pubkeyMgr.GetSignPubKeys()`: a node only fetches items for vaults it is a member of. Same data as `/thorchain/keysign/{height}/{pubkey}`                                                                                                                                                                                     |
| Persist          | `bifrost/signer/sign.go` `storeTxOut`; LevelDB store in `bifrost/signer/storage.go`                                                          | Items survive restarts; the item (with `SignedTx`/`Checkpoint`) is removed after a successful broadcast                                                                                                                                                                                                                                   |
| Sign + broadcast | `sign.go` `processTransaction` -> `signAndBroadcast`                                                                                         | ZEC `tex` destinations skipped; `chain.IsBlockScannerHealthy()` must be true; if `item.SignedTx` is set it rebroadcasts the saved bytes and never re-signs; per-chain/vault lock `chainVaultLock`                                                                                                                                         |
| TSS              | `bifrost/tss/tss_signer.go` `RemoteSign`; `bifrost/tss/keysign_error.go`                                                                     | `KeysignError.IsTerminalRound()` sets `Round7Retry` (signature may already exist; do not re-sign with new inputs). Blame -> `PostKeysignFailure` (`bifrost/thorclient/thorchain.go`), called by each chain client on keysign error (evm, ethereum, gaia, solana, tron, xrp, monero; UTXO via `shared/utxo/signer.go`), not from `sign.go` |
| Keysign fail     | `x/thorchain/handler_tss_keysign.go`                                                                                                         | `MsgTssKeysignFail` is a voter: the reporter gets `ObserveSlashPoints`; blamed nodes are slashed only once vault members reach consensus                                                                                                                                                                                                  |
| Instant observe  | `sign.go` `shouldAutoObserve` -> `observer.ObserveSigned`                                                                                    | Only after a successful broadcast and only when `SignTx` returned a `TxInItem`                                                                                                                                                                                                                                                            |
| Observed out     | Same attest/quorum path as inbound with `inbound=false`; `handleObservedTxOutQuorum`, `ensureVaultAndGetTxOutVoter`                          | At quorum, `processOneTxIn` builds the outbound msg and the internal handler runs `x/thorchain/handler_outbound_tx.go` -> `handler_common_outbound.go` (walks back from inbound consensus height to match the scheduled `TxOutItem`, sets the out hash on the inbound voter; no match = signer slashed for a missing tx out)              |
| Reschedule       | `x/thorchain/manager_slasher_current.go` `LackSigning`                                                                                       | Items unsigned after `SigningTransactionPeriod` (300 blocks) are re-assigned; XMR, EVM aggregator and EVM token outbounds use `types.ExtendedOutboundSigningPeriodMultiplier`. `MaxOutboundAttempts` 0 = no attempt cap; `RescheduleCoalesceBlocks` 0 = off                                                                               |

## Errata (reorg)

Chain client sends an `ErrataBlock` on `globalErrataQueue` -> `observe.go` `processErrataTx` -> `attestErrata` -> `SendQuorumErrataTx` -> injected `MsgErrataTxQuorum` -> `x/thorchain/handler_errata_tx_quorum.go`. A committed errata marks the inbound voter `Reverted`, which turns any later quorum on it into a no-op.

## Committed feedback to bifrost

Bifrost subscribes to ebifrost events (`SubscribeToEvents`). `attestation_gossip.go` `handleQuorumTxCommitted` calls back into `observe.go` `handleObservedTxCommitted`, which removes the item from the deck. A tx that keeps re-attesting after commit means this callback did not fire.
